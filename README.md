# Reliable-Agent

A curated list of tools for improving the reliability of AI agents.

## Coding Reliable Agents

- [Trustabl Agent Reliability Analyzer](https://github.com/trustabl/agent-reliability-analyzer) — Deterministic scanner for detecting agent reliability issues in code before production, with support for major agent frameworks and SDKs.
- [Trustabl Agent Reliability Rules](https://github.com/trustabl/agent-reliability-rules) — Detection rule packs used by the Trustabl Analyzer to identify reliability, safety, and security risks across agent frameworks and environments.
- [Trustabl Agent Reliability Skills](https://github.com/trustabl/agent-reliability-skills)
- [Trustabl Agent Dashboard](https://github.com/trustabl/agent-dashboard)

## Evaluation and testing

- [promptfoo](https://github.com/promptfoo) — Test and evaluate LLM applications with configurable test cases, assertions, and red-team scans.
- [DeepEval](https://github.com/confident-ai/deepeval) — Open-source evaluation framework with metrics and tests for LLM applications and agents.
- [Ragas](https://github.com/explodinggradients/ragas) — Evaluation toolkit for LLM applications, including retrieval-augmented generation.
- [Inspect AI](https://github.com/UKGovernmentBEIS/inspect_ai) — Evaluation framework for measuring AI capabilities and behavior across tasks.
- [Braintrust](https://www.braintrust.dev/) — Platform for LLM evaluation, experiment tracking, and production monitoring.

## Tracing and observability

- [LangSmith](https://www.langchain.com/langsmith) — Trace, inspect, evaluate, and monitor agent and LLM application runs.
- [Langfuse](https://github.com/langfuse/langfuse) — Open-source LLM engineering platform for tracing, evaluation, and prompt management.
- [Arize Phoenix](https://github.com/Arize-ai/phoenix) — Open-source observability and evaluation for LLM applications, including tracing and retrieval analysis.
- [Weave](https://github.com/wandb/weave) — Track, inspect, and evaluate LLM application calls and experiments.
- [Pydantic Logfire](https://github.com/pydantic/logfire) — Observability for Python applications, with support for tracing LLM and agent workflows.

## Guardrails and security

- [Guardrails AI](https://github.com/guardrails-ai/guardrails) — Add input/output validation and structured checks to LLM applications.
- [NVIDIA NeMo Guardrails](https://github.com/NVIDIA/NeMo-Guardrails) — Toolkit for adding programmable safety and control rails to conversational AI systems.
- [Giskard](https://github.com/Giskard-AI/giskard) — Test and scan AI applications for quality, robustness, and security risks.

## Agent benchmarks and environments

- [BrowserGym](https://github.com/ServiceNow/BrowserGym) — Benchmark and environment framework for evaluating web-browsing agents.
- [OSWorld](https://github.com/xlang-ai/OSWorld) — Benchmark environment for evaluating agents on realistic computer-use tasks.
- [τ-bench](https://github.com/sierra-research/tau-bench) — Benchmark for evaluating agents on tool-use tasks in realistic domains.
- [AgentBench](https://github.com/THUDM/AgentBench) — Benchmark suite for evaluating LLM-based agents across interactive environments.

## Contributions

Contributions are welcome. Please suggest tools that help test, observe, secure, or benchmark AI agents. Include a short description and place each entry in the most relevant category.

> Tool capabilities and project status can change. Check each project's documentation and license before adopting it.
